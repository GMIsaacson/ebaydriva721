# Run 015 — UI Excellence Team Operating Contract

## FROZEN STATUS

**Run:** `UIX-015`  
**Lifecycle:** **FROZEN**  
**Effective:** 2026-08-28  
**New assignments:** **REJECT**  
**Existing artifacts/evidence:** **PRESERVE READ-ONLY**  
**Standing external authority:** None

Run 015 is frozen by owner direction after qualification experiments. It must not be used for new UI implementation, primary website creative direction, or automatic fallback from another Factory team.

The freeze is reversible only through:
1. fresh owner approval;
2. a current A0 reactivation/extension decision;
3. an explicit revised mission and qualification plan.

The original mission, roles, UIX-100 rubric, receipts, screenshots, runtime evidence and failed qualification artifacts remain preserved for audit and future learning.

## Historical mission

Run 015 was created to take an existing working UI and improve usability, visual hierarchy, typography, layout, interaction quality, responsive behavior, accessibility, consistency, and perceived product quality without silently changing approved product logic.

It was explicitly a shared specialist capability and did not replace Software Product Engineering or the Website Business Team.

## Freeze rationale

Capable Hands experiments demonstrated useful strengths in fail-closed evidence, browser rendering, challenger mechanics and quality scoring, but the team repeatedly produced weaker commercial website creative direction than the pre-015 Website Business + Run 014 stack. The Factory is therefore freezing Run 015 rather than continuing to optimize or broaden it.

Reusable lessons/tooling may be adopted elsewhere, but that does not reactivate Run 015.

## Authority boundary while frozen

Run 015 may not:
- accept or execute new assignments;
- produce new design artifacts;
- deploy or publish;
- mutate production;
- contact customers;
- spend money;
- act as the primary creative owner for a website;
- silently substitute for another team.

Historical evidence remains readable.
