# Run 007 — Systems Intelligence & Development Team

## Purpose
Continuously identify missing capabilities, recurring friction, emerging risks, duplicated work, and high-value opportunities across the operating system before they become owner-visible problems.

## Core loop
Observe → Detect → Evidence → Challenge → Score → Propose → Plan → Gate → Build via Agent Factory → Verify → Register Capability → Resume Observation

## Units
1. Systems Scout (Thinker)
2. Systems Architect (Planner)
3. Factory Orchestrator (Builder)
4. Challenger & Verification Agent (Reviewer)

## Authority
- Observe broadly across approved internal sources.
- Create internal discovery candidates and recommendations.
- Produce plans and build specifications.
- No vendor action, spending, subscription/account changes, destructive actions, or external communication without separate explicit authorization.
- Builder routes approved work through existing Agent Factory; it does not create a parallel execution framework.

## Initial assignment
Evaluate the proposed personal/business operations modules, discover additional missing capabilities, identify shared infrastructure, detect duplication, and recommend the optimal build sequence.

## Initial candidate modules
- Inbox & Obligation Manager
- Bills / Payments / Renewal Manager
- Waiting-On / Follow-Up Manager
- Document & Expiration Manager
- Project / Workload Control Manager
- Account & Security Watch
- Purchase / Warranty Manager

## Success condition
Run 007 is successful when it produces a prioritized, evidence-backed capability roadmap that distinguishes:
- shared infrastructure to build once,
- modules to build next,
- modules to defer,
- existing capabilities to reuse,
- risks or blind spots the owner has not yet identified.
