# Run 015 — UI Excellence Team

Run 015 is Factory 1's reusable UI/UX specialist team.

It exists to take an already-working interface and make it materially better rather than merely restyling it. The team combines **current niche-web benchmarking, product-personality definition, UX architecture, divergent art direction, portfolio visual-memory checks, design-system normalization, interaction design, frontend polish, responsive/accessibility review, structured scoring, and independent visual QA**.

## What changed in v2
Run 015 may no longer choose a visual system from its own habitual preferences and then justify it afterward.

Before implementation it must:
1. inspect **8–15** current strong interfaces, with at least **8 usable references and 4 direct-niche references**;
2. record typography/font families where inspectable, palette, layout, density, geometry, component grammar, interaction, data presentation, imagery/iconography, mobile behavior and the distinctive idea behind each reference;
3. define the product personality and visual anti-goals before selecting colors or fonts;
4. produce at least **three genuinely divergent** visual directions;
5. fingerprint those directions using the 11-dimension visual genome;
6. compare them with the durable Run 015 portfolio registry;
7. revise unexplained unrelated-product similarity above the configured threshold before implementation.

A list of links without analysis does not satisfy the benchmark stage. Three recolors of the same design do not satisfy the art-direction stage.

## Portfolio memory
`portfolio/visual-genome-registry.json` stores visual fingerprints of completed Run 015 products. It is used to detect accidental repetition, **not** as a reusable style template.

The registry is currently seeded with Asteron and Njia because owner review exposed meaningful convergence between those unrelated outputs.

## Quality target
The weighted UIX-100 remains comparable to earlier results:
- `UIX-100 >= 92` for production-quality delivery;
- `>=96` is exceptional;
- Visual hierarchy, UX clarity, responsive execution, accessibility, and **Brand Distinction** must each be `>=90`;
- **Niche Appropriateness >=90**;
- **Portfolio Distinction >=90**.

## Non-regression rule
The v2 extension is additive. The pre-existing Run 015 protections remain mandatory: exact artifact lineage, mobile/tablet/desktop evidence, functional-equivalence checks, unauthorized-logic-change rejection, independent QA, no self-approval, bounded repair surfaces, protected baselines, and no score/check regression.

Historical accepted artifacts remain historically verifiable under the evidence contract that applied when they passed. New assignments cannot use that compatibility path to avoid the v2 gates.
